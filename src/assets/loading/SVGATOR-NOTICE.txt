Welcome to SVGator!

With SVGator you can create vector animations and export them as production-ready files in the following formats:


1. Vector formats

- SVG with CSS only animations can also support interactivity presets (on mouse over)
- SVG with Javascript supports more interactivity presets (on mouse over, on click, on scroll into view, and second click or mouse out events)
- SVG with Javascript - Programmatic allows you to control the animation programmatically using SVGator’s Player API.  Learn more about programmatic animations.
- Lottie Json 

2. Raster formats

Video formats up to @60 FPS and 4K resolution (3840 x 2160):
- MP4 (codec H.264 / AVC)
- AVI (codec H.264 / AVC)
- MOV with transparency (codec Apple ProRes)
- WebM with transparency (codec Google’s VP9)
- MKV (codec mpeg4 / DivX)
